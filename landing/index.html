Capabilities

Gesture-first creation designed for spatial workflows

ARIA combines webcam tracking, real-time rendering, and interaction-aware controls so ideas can move directly from hand motion into editable visual objects.

DRAW

Air Draw

Track index-finger motion and convert gestures into smooth real-time strokes.

SPRITE

Sprite Manipulation

Convert sketches into transparent objects, then select, drag, and resize them in the scene.

FLOW

Workflow Switching

Move between draw, select, and transform modes without breaking creative flow.

VOICE

Voice Commands

Trigger actions and scene controls using speech for hands-free interaction.

SIGNAL

Calibration + Overlay

Use visual diagnostics and overlays to improve low-light tracking and system confidence.

Workflow

How ARIA Works

Step 01

Draw

Use hand gestures to create smooth air-drawn strokes with adaptive filtering.

Step 02

Convert + Manipulate

Turn strokes into transparent movable sprites and resize or reposition them in space.

Step 03

Control

Use toolbar input, mouse fallback, or voice commands to switch modes and execute actions.

Local Setup

Run ARIA Locally

Install

From the project root (aria/) run:

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Launch

Start the local product:

python main.py

Tip: wait for calibration to complete before drawing.
