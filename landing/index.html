Workflow

How ARIA Works

The interaction model stays intentionally simple: draw with motion, promote the sketch into an object, then control the scene with gestures, UI, mouse fallback, or voice. The workflow is spatial, but the mental model remains fast to learn.

Step 01

Draw

Use hand gestures to create smooth air-drawn strokes with adaptive smoothing and motion filtering.

Step 02

Convert + Manipulate

Turn strokes into transparent movable sprites and resize or reposition them in the workspace.

Step 03

Control

Use toolbar input, mouse fallback, or voice commands to switch modes and execute actions quickly.

Local Setup

Run ARIA Locally

Install the project once, launch the local workspace, then wait for calibration to finish before drawing or manipulating objects. The product is built as a local desktop experience, so this page points you directly into the correct run flow.

Install

From the project root (aria/) run:

python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Launch

Start the local product:

python main.py
Tip: wait for calibration to complete before drawing.
